# KIZZIMO iOS Power Lab

Native SwiftUI project for iOS power and performance diagnostics.

Features: battery, thermal state, Low Power Mode status, brightness, app-local QoS experiments, display/touch timing, offline plist editing, and JSON reports.

This app does not control other apps, system daemons, or CPU/GPU frequencies.

The GitHub Actions workflow builds an unsigned iOS IPA. A valid Apple signing step is required before installation on an iPhone.
